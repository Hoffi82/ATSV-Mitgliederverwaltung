# ATSV-Mitgliederverwaltung

Digitale Mitgliederverwaltung für den ATSV Forchheim e.V.

## Ziel

Die Anwendung soll die Vereinsverwaltung digitalisieren und Papieraufwand reduzieren.

Geplante Bereiche:

- Mitgliederverwaltung
- Online-Aufnahmeanträge
- Prüfung und Freigabe von Anträgen
- Mitgliederakten und Dokumente
- Beitragsverwaltung
- Benutzer- und Rollenverwaltung

## Design

ATSV-Vereinsdesign mit Schwarz, Rot und dem ATSV-Wappen.

## Datenschutz

Personenbezogene Mitgliederdaten werden nicht im Git-Repository gespeichert. Die produktiven Daten sollen später über eine sichere Datenbank und eine geschützte Anwendung verwaltet werden.
